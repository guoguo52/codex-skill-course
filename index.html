核心逻辑

为什么是 Codex + Skill

Codex 提供通用的执行力，Skill 提供行业的专业度。两者相加，才是一条能接单、能交付、能复用的工作流。

  1. 01

    Codex 是执行者

    它能写代码、跑命令、调用工具，把一句想法真正落地成文件、页面和视频。

  2. 02

    Skill 是方法论

    把某个行业该怎么做，写成可复用的指令与流程，让每次产出的质量都稳定。

  3. 03

    一加一大于二

    通用智能体配上行业 skill，等于一条针对具体场景的自动化生产线。

  4. 04

    门槛其实很低

    不需要会写代码。装好 skill，照着一个案例跑一遍，就能感受到它怎么工作。

课程大纲

一小时，六个模块

从建立心智模型，到看完六个领域的真实成品，最后给出可复制的上手路线。

  1. 00–08 分

    开场：Codex 与 Skill 分别是什么

    先分清两个概念，建立同一个讨论坐标系。

  2. 08–18 分

    核心逻辑：通用引擎加专业方法

    用一张图讲清它们怎么配合，以及为什么组合之后能干活。

  3. 18–43 分

    案例巡礼：六个领域逐个看

    每个领域 3 到 4 分钟，看真实成品，同时指出背后用了哪类 skill。

  4. 43–52 分

    上手路线：装 skill，跑通第一个案例

    从本机案例目录里挑一个，照着启动说明运行一次。

  5. 52–60 分

    答疑与延伸：继续逛本机案例

    回答提问，并给出本机其他案例目录的浏览顺序。
