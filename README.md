# Codex + Skill 应用入门课 · 站点

一小时的入门科普与案例展示站，纯静态、零依赖、离线可打开。

## 打开方式

直接双击 `index.html` 即可。页面里的「打开目录」按钮用 `file://` 跳转，双击打开时可直接跳到本地案例目录。

也可以用任意静态服务器打开：

```bash
cd codex-skill-course
python -m http.server 8899
```

浏览器访问 `http://127.0.0.1:8899`。注意：用服务器打开时，`file://` 跳转会被浏览器拦截，请按卡片上显示的路径手动前往对应目录。

## 文件结构

```
codex-skill-course/
├─ index.html    页面结构
├─ styles.css    设计与动效
├─ data.js       案例与补充目录数据
├─ script.js     渲染、动效与交互
└─ assets/cases/ 15 张案例封面（本地复制，可离线显示）
```

## 内容

- 6 大领域：网站与落地页、海报与品牌视觉、电商与产品广告、口播与讲解视频、AI 音乐视频、短剧与影视工业
- 15 个真实案例，均来自本机成品目录
- 29 个本机补充案例目录，按领域分组
